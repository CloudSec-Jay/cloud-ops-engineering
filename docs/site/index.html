Three parts of one system: Terraform provisions it, GitOps ships to it, and SLOs decide whether a release survives.

  1. 01 / Provision

    Infrastructure as code with drift detection

    Terraform builds the AWS dev environment. A daily read-only plan opens an issue when live infrastructure no longer matches main.

    Terraform · GitHub OIDC · ActionsPlanned
  2. 02 / Deliver

    GitOps delivery with automatic rollback

    Merging a PR is the only way to deploy. Each change ships as a canary and reverts on its own when error rate or latency breaks the threshold.

    Argo CD · Argo Rollouts · k3sPlanned
  3. 03 / Measure

    SLOs and error budgets

    Availability and latency SLOs with multi-window burn-rate alerts. The canary analysis judges every release against the same SLIs.

    Prometheus · Alertmanager · GrafanaPlanned

↺ Rollback loop: when Measure fails a canary check, Deliver reverts to the last stable release.
